# Listing and area views

The results map renders rental and destination pins. Listing details combine nearby transit and amenities with the rent benchmark and district facts. Districts can show renter share, shelter-cost estimates, transit coverage and mapped development applications under review.

Monthly cost adds asking rent and a GRT monthly pass. The browser remembers the U-Pass choice and uses a $0 incremental transit charge when selected. Demo listings carry a visible demo label.

Source files include `apps/web/src/components/map/results-map.tsx`, `apps/web/src/components/listing/`, and `apps/web/src/components/areas/`.
